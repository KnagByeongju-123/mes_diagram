이 프로그램은 무엇을 하는 건가요?

회사에서 사용할 화면과 자료 저장 공간을 블록으로 그려서 설계하는 도구입니다. 먼저 메뉴와 화면을 만들고, 화면에서 사용할 자료표를 연결한 뒤 [▶ 시스템 생성]을 누르면 실제로 사용할 수 있는 화면 파일을 만들어 줍니다.

① 처음 시작하기

  1. 처음이라면 상단 [설계 ▾]를 누릅니다.
  2. 업종에 맞는 기본 구조부터 빠르게 시작하려면 [설계 ▾ → 🗂 구성 보관함]을 사용합니다.
  3. 질문에 답하면서 만들고 싶으면 [문답으로 만들기]를 사용하면 됩니다.
  4. 직접 하나씩 만들고 싶으면 [＋ 추가 ▾]에서 필요한 블록을 추가합니다.
가장 쉬운 방법: 회사 업종이 목록에 있으면 [구성 보관함]에서 업종을 고르는 것이 가장 빠릅니다. 필요한 메뉴만 남기고 이름을 고쳐 쓰면 됩니다.

③ 선으로 연결하는 방법

블록 오른쪽에 있는 작은 ○를 마우스로 잡고, 연결할 블록까지 끌어 놓으면 됩니다.

  1. 대메뉴 → 중분류: 이 메뉴 안에 들어간다는 뜻입니다.
  2. 중분류 → 화면: 이 분류 안에서 사용할 화면이라는 뜻입니다.
  3. 화면 → 테이블: 이 화면이 이 자료표를 사용한다는 뜻입니다.
  4. 화면 → 화면: 한 화면에서 다른 화면으로 이동하는 흐름입니다.
  5. 테이블 → 테이블: 두 자료표가 서로 연결되어 있다는 뜻입니다.
어떤 선을 써야 할지 몰라도 괜찮습니다. 블록 종류에 맞춰 선 종류를 자동으로 판단합니다.

④ 이름과 내용을 수정하는 방법

  1. 수정할 블록을 한 번 클릭합니다.
  2. 오른쪽 편집창에서 이름, 설명, 화면 종류, 항목 등을 바꿉니다.
  3. 블록은 마우스로 잡아 원하는 위치로 옮길 수 있습니다.
  4. 대메뉴·중분류·화면을 더블클릭하면 미리보기가 열립니다.
  5. 블록이나 선을 지우려면 선택한 뒤 Delete를 누릅니다.

화면을 보기 좋게 정리하려면

[설계 ▾ → 자동정렬]을 누르면 블록이 자동으로 정리됩니다. 화면 전체를 한 번에 보려면 [전체 보기]를 누릅니다.

⑤ 저장하고 다시 여는 방법

작업 중 내용은 현재 브라우저에 자동으로 임시 저장됩니다. 별도로 보관하려면 상단 [저장 ▾] 메뉴를 사용합니다.

  • Supabase에 저장: 인터넷 DB에 설계를 저장합니다. 여러 PC에서 사용할 때 편리합니다.
  • 설계 JSON 내려받기: 설계 내용을 파일 한 개로 PC에 저장합니다.
  • 설계 JSON 파일 열기: 전에 내려받은 설계 파일을 다시 불러옵니다.
Supabase를 사용하지 않아도 JSON 파일로 저장하고 불러올 수 있습니다.

⑥ 실제 시스템 파일 만들기

  1. 먼저 오른쪽 위 [✓ 설계검증]을 눌러 빠진 연결이나 문제가 있는지 확인합니다.
  2. 문제가 없으면 [▶ 시스템 생성]을 누릅니다.
  3. 생성창에서 [단일 index.html] 또는 [ZIP]을 내려받습니다.
  4. 단일 index.html은 한 파일로 간단히 확인할 때 좋고, ZIP은 파일별로 나누어 사용할 때 좋습니다.
처음 확인할 때: [단일 index.html]을 내려받아 더블클릭으로 열어 보는 방법이 가장 간단합니다.

⑦ 빠른 자동제작 — 시간을 줄이는 방법

  1. 화면을 하나 선택하고 오른쪽의 [⚡ 화면 자동완성]을 누르면, 필요한 테이블이 없을 때는 자동으로 만들고 기본 칼럼도 채웁니다.
  2. 이어서 기본키·필수 항목, 영문 칼럼명, 파일명까지 자동으로 정리합니다. 기존 칼럼은 지우지 않습니다.
  3. 중분류를 선택하면 [⚡ 중분류 화면 자동추천]이 보입니다. 필요한 화면만 체크하고 [선택 화면 한꺼번에 만들기]를 누릅니다.
  4. 생산·품질·금형·수주·출하·자재·안전 등 중분류의 성격을 보고 보통 많이 쓰는 등록·현황·대시보드 화면을 추천합니다.
가장 빠른 방법: 대메뉴와 중분류 이름만 먼저 만든 뒤, 중분류의 [화면 자동추천]으로 기본 구조를 만들고 필요한 부분만 수정하세요.

⑧ 구성보관함 — 업종별 기본 구조로 시작하기

  1. 상단 [설계 ▾ → 🗂 구성 보관함]을 누릅니다.
  2. 프레스·금형, 자동차부품, 일반 제조, 기계가공, 철강·무역, 물류 등 회사와 가까운 업종을 고릅니다.
  3. [새 설계로 적용]은 현재 설계를 비우고 선택한 업종 구조로 시작합니다.
  4. [현재 설계에 추가]는 지금 작업을 유지하면서 필요한 업종 구성을 덧붙입니다.
  5. 테이블·기본칼럼 자동 생성을 체크하면 대분류·중분류·화면뿐 아니라 저장 테이블과 기본 항목까지 함께 만듭니다.
모듈보관함과 차이: 모듈보관함은 화면·테이블 같은 작은 기능 묶음을 재사용하고, 구성보관함은 업종별 시스템 전체 뼈대를 빠르게 시작할 때 사용합니다.

⑨ 실습하기 — 직접 만들어 보세요

아래에서 연습할 종류를 고르면 빈 설계 화면에서 직접 만들어 볼 수 있습니다. 왼쪽 아래에 작은 실습 도우미가 열리고, 지금 해야 할 일과 완료 여부를 자동으로 알려줍니다.

현재 작업이 있어도 괜찮습니다. 실습을 시작하면 실습 전 설계를 따로 백업합니다. 실습이 끝난 뒤 [실습 전 설계 복원]으로 돌아갈 수 있습니다.
막히면 한 단계씩 진행하면 됩니다. 먼저 [💡 방법 힌트]를 보고 직접 해보세요. 그래도 어렵다면 [▶ 다음 한 단계 완성]을 누르면 현재 막힌 단계만 자동으로 만들어 주고 다음 단계에서 멈춥니다. 자동 ①~③ 실습에서는 실제 자동추가 버튼을 직접 눌러 연습할 수 있습니다.
